# Andrei Kaliuzhny — Portfolio v4 (editorial)

Static HTML/CSS/JS site for GitHub Pages. Upload the **contents** of this folder to the repository root and enable Settings → Pages → Deploy from a branch → main / (root).

## Editorial design updates
- Global background: `#F1ECEC`. Dark typography on light backgrounds: `#333333`. White type remains on dark panels.
- Selective Georgia Italic accents with `letter-spacing: -0.05em`.
- Story-led editorial case layouts: panoramic, offset, asymmetric split, mosaics and gallery compositions.
- Existing PDF-derived HTML copy and individual WebP files preserved; exact visual/copy repeats reduced.
- No build step, external framework or API required.

## Contents
- `index.html` — home page
- `projects/*.html` — 9 project stories
- `style.css` / `script.js` — presentation and scroll reveals
- `assets/*.webp` — extracted project visuals
- `source-content.json` — source document mapping for editorial edits

Some customer-facing graphics and metrics may be confidential: review publication rights prior to making a public repository.
